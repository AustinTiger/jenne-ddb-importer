# Jenne D&D Beyond Importer (`jenne-ddb-importer`)

A modern, fast, and completely self-hosted D&D Beyond integration module for Foundry VTT (v12, v13, and v14).

## Features
- **100% Self-Hosted**: Communicates directly with your self-hosted [`jenne-ddb-proxy`](https://github.com/AustinTiger/jenne-ddb-proxy).
- **Patreon-Free**: All features (character synchronization, monster token/avatar generation, enhanced data, and adventure munching) are natively unlocked.
- **Direct Adventure Importer**: Downloads full chapters, formatted text, artwork, and scenes directly from D&D Beyond into `DDB Adventures` and `DDB Journals` compendiums.
- **Full Content Muncher**: Monsters, Spells, Items, Classes, Feats, Species, Backgrounds, and Vehicles.
- **Jenne Suite Integration**: Integrates directly with the **Jenne Suite** sidebar controls.
- **Automatic Settings Migration**: Automatically migrates your existing Cobalt session cookie and preferences from `ddb-importer` on first launch.

## Setup
1. Enter your **Cobalt Session Cookie** in **Module Settings $\rightarrow$ Jenne D&D Beyond Importer**.
2. Set your **Proxy URL** (default: `https://ddb-proxy.clemson.engineer`).
3. Click the **DDB Importer** icon in the **Jenne Suite** sidebar controls or open from the Compendium tab!
